## Reconciliation checklist

- [ ] Every new source contains the intended paper rather than an error, CAPTCHA, login, or metadata page.
- [ ] Every retained source has a human-readable bibliographic/role title.
- [ ] A `START HERE` evidence map explains evidence tags and points to the canonical project register.
- [ ] Every decision-relevant candidate has a `source-resolution.csv` row and stable citation key when retained.
- [ ] Broken imports are replaced before NotebookLM synthesis relies on them.
- [ ] Unassessed candidates are fully reviewed, screened out, superseded, or converted to an exact surfaced access request.
- [ ] Every retained full source has a canonical private-repository copy and a verified NotebookLM source object.
- [ ] Copyright, license, or redistribution status was not used to omit a source from either private store.
- [ ] Duplicate and superseded objects are proposed for cleanup instead of accumulating silently.
- [ ] The author explicitly confirmed the exact irreversible deletion set before deletion.
- [ ] The source manifest, evidence register, missing-copy queue, and NotebookLM working set agree.
