# Exemplar-paper routing across HCI-stack

Use complete exemplar papers as worked examples of research structure and evidentiary reasoning; do
not imitate sentences or treat prestige as evidence that a choice is correct. Record each exemplar's
identity (version, citation, venue, year, full-copy location/source ID), the section examined, its
structural and evidentiary moves, what is project-specific and must not transfer, and which project
choice it informs. Keep exemplar analysis out of the related-work matrix unless the exemplar is
substantively relevant to this project's problem or approach.

## Phase routing

| Phase | Read these exemplar sections | Learn and transfer |
|---|---|---|
| 0 — Office Hours | Abstract, Introduction, conclusion | which problems become consequential contributions; scope and feasibility |
| 1 — Motivation and contributions | Abstract, Introduction, Related Work, contribution statements | evidence chains, why-now, prior-work synthesis, gap precision, empirical waist |
| 2 — Solve the problem well | Formative work, design process, system, iterations, pilots | how user evidence changes design; alternatives; reproducible system description |
| 3 — Validation | Questions, design, measures, baselines, Results, limitations | methodological precedents, construct operationalization, evidence-to-claim calibration |
| 4 — Visual presentation | Hero figure, diagrams, charts, captions | visual argument, reading order, encodings, captions stating takeaway and boundary |
| 5 — Paper writing | Corresponding section of each exemplar plus whole-paper argument | section architecture, transitions, hourglass movement, lexical consistency |
| 6 — Video | Paper narrative, hero scenario, figures | one problem, one mechanism, visible before/after, scoped evidence in 30–90 seconds |

Each phase accepts its own exemplar set and may reuse prior analyses. If no exemplar is supplied,
propose three to five candidates and let the author choose before treating any as a house style.

## Current four-paper pattern library

When the author supplies the complete works, use these as initial exemplars:

- **StrengthGaming:** authoritative public-health and exercise-science evidence becomes a concrete
  design constraint; useful in Phases 1, 2, and 5.
- **MRDrum:** broad activity class narrows to a specific empirical waist and reopens through a
  shared temporal-motor mechanism; useful in Phases 1, 4, 5, and 6.
- **TurnAhead:** a dated enabling change and mechanism-level closest-predecessor comparison sharpen
  why-now and novelty; useful in Phases 1, 2, and 5.
- **AirRacket:** a diagnostic limitation reveals a perceptual insight and reusable design strategy;
  useful in Phases 1, 2, 3, and 5.

These are starting hypotheses. Re-open the complete papers and examine the phase-relevant sections
before transferring a pattern.
